# 编程与软件工程

这里整理编程语言、算法、软件工程、系统设计和开发工具相关书籍与资料。

## 外部书单

- [中文编程书籍列表](https://github.com/justjavac/free-programming-books-zh_CN)
  - 中文编程书籍和学习资料，包含 AI、C/C++、Go、Java、Python 等分类。
- [中文编程书籍列表：AI 分类](https://github.com/justjavac/free-programming-books-zh_CN#ai)
  - 直接查看其中的人工智能和机器学习资料。
- [Free Programming Books](https://github.com/EbookFoundation/free-programming-books)
  - 英文、中文及其他语言的免费编程书籍和学习资源目录。
- [Awesome Free Programming Books](https://github.com/holasoymalva/awesome-programming-books)
  - 按语言、主题和难度整理的免费编程书籍。
- [Influential CS Books](https://github.com/stjepanjurekovic/influential-cs-books)
  - 计算机科学和编程领域经典书籍清单。
- [Programming-Books](https://github.com/CodesdaLu/Programming-Books)
  - 包含部分直接存放的电子书文件，使用前需要逐本确认版权和许可证。
