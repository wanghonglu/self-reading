# 我的阅读站

这里用来整理适合通勤和空闲时间阅读的书籍、资料和笔记，包含 AI、编程、金融和小说。

## 书架

- [AI 与机器学习](books/ai/README.md)
- [编程与软件工程](books/programming/README.md)
- [股票、金融与证券](books/finance/README.md)
- [小说](books/novels/README.md)

## 阅读说明

- 每本书单独放在一个目录中。
- 每章单独使用一个 Markdown 文件，方便手机加载和继续阅读。
- `index.md` 或 `README.md` 用作书籍目录。
- 图片放在对应书籍目录下的 `images/` 中。
- PDF、EPUB 等原始文件放到对应书籍目录的 `downloads/` 中。

## 目录结构

```text
books/
├── ai/
│   ├── README.md
│   └── book-name/
│       ├── README.md
│       ├── 01-introduction.md
│       └── images/
├── programming/
│   └── README.md
├── finance/
│   ├── README.md
│   └── book-name/
└── novels/
    ├── README.md
    └── book-name/
```
